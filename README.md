## 📌 Executive Overview
Full-stack PHP 8+ and SQLite clinical booking system featuring practitioner schedules, patient reservation queues, and a session-authenticated staff management panel.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pushpikaodisha/medcare.git
   cd medcare
   ```

2. **Launch locally:**
   Start PHP built-in server: `php -S localhost:8000` and open `http://localhost:8000/`. Staff Portal (`admin.php`) demo credentials: `admin` / `medcare123`.
